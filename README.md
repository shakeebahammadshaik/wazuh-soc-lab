
# Next-Gen SOC Lab: Real-Time Detection & Incident Response with Wazuh

## Project Overview
This project documents the development of a hands-on Security Operations Center (SOC) lab using Wazuh SIEM, Windows endpoint monitoring, and Kali Linux for authorized security testing.

The objective is to practice security log collection, alert monitoring, threat detection, investigation, and incident response.

## Lab Architecture
- Wazuh: Security monitoring and alert analysis
- Windows 10 VM: Endpoint under monitoring
- Kali Linux VM: Authorized security testing
- Oracle VirtualBox: Virtualization platform

## Project Objectives
- Deploy and configure the Wazuh environment.
- Connect a Windows endpoint using the Wazuh agent.
- Monitor Windows security events.
- Investigate authentication-related security alerts.
- Document findings and recommended remediation.
- Maintain evidence of lab activities.

## Repository Structure
- `setup/` - Installation and configuration guides
- `screenshots/` - Visual evidence from the lab
- `detections/` - Test cases and detection findings
- `incident-reports/` - Investigation and remediation reports

## Skills Practiced
Wazuh SIEM, SOC Monitoring, Security Log Analysis,
Alert Triage, Threat Detection, Incident Investigation,
and Incident Response.
